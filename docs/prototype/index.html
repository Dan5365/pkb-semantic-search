Прототип модуля семантического поиска

Макеты ключевых экранов. Данные тестовые, заметки синтетические (NFR-9).

Экран 1

Поиск

Запрос, выбор стратегии и K, ранжированный список с рангами и временем ответа.

 Экран 2

Выбор стратегии

Три стратегии (sparse, dense, hybrid RRF) с их параметрами: модель, индекс, ef_search, K и константа k.

 Экран 3

Сравнение результатов

Один запрос на трёх стратегиях в трёх колонках: ранги, note_id и chunk_id, режим разметки для разметчика.
