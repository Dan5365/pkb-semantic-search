# Прототип интерфейса: PKB Semantic Search

Макеты трёх ключевых экранов. Это статичные HTML-страницы без сервера: откройте `index.html` в браузере, все ссылки между экранами работают.

## Состав

| Файл | Экран | Что показывает | Требования |
|---|---|---|---|
| `index.html` | Оглавление | Ссылки на экраны и таблица соответствия требованиям | — |
| `01-search.html` | Поиск | Запрос, выбор стратегии и K, результаты с рангом и оценкой стратегии, время ответа | FR-8, FR-10 |
| `02-strategy.html` | Выбор стратегии | Карточки sparse / dense / hybrid (RRF) и их параметры (метрика, индекс, ef_search, K) | FR-5, FR-6, FR-7 |
| `03-comparison.html` | Сравнение результатов | Один запрос на трёх стратегиях в трёх колонках с рангами, `note_id` и `chunk_id`, режим разметки | FR-9, FR-11 |
| `style.css` | — | Общие стили всех экранов | — |

## Как смотреть

Откройте `docs/prototype/index.html` двойным щелчком или через любой браузер. Внешних зависимостей, сборки и интернета не нужно.

## Примечания

- Сырые оценки не сравниваются между стратегиями: sparse — BM25, dense — cosine, hybrid — RRF. На экранах показаны ранги в списке, а оценка подписана своей стратегией.
- Форма ответа и поля (`rank`, `note_id`, `chunk_id`, `score`, `excerpt`) соответствуют `docs/api_examples.md`. Пагинации и фильтров по тегам и дате в макетах нет, потому что их нет в контракте.
- Метрики Precision@K, Recall@K и MRR по всему набору запросов не показаны: их выводит экран результатов эксперимента.
- Режим разметки на экране 3 предназначен только для разметчика. Его отметки идут в размеченный набор запросов, а не в пользовательские данные.
- Все числа в макетах — примерные, для демонстрации. Заметки синтетические, как того требует NFR-9.
- Макеты рассчитаны на настольный экран; на узком экране боковое меню скрывается.
